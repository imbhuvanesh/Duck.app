## DUCK

### Your files. Automatically organised.

DUCK is a lightweight Windows application that automatically keeps your files organised. It helps you maintain a tidy workspace with less manual effort, making file management simpler and more convenient.

## ✨ About the Project

DUCK is built around one simple idea: **your files should organise themselves.**

Instead of spending time manually sorting files, DUCK aims to make everyday file management easier through automatic organisation.

## 🎯 Project Goal

To create a lightweight, convenient Windows application that helps users keep their files organised without unnecessary complexity.

## 🖥️ Platform

- Windows
